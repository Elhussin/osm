# التطبيق الجديد

هذا هو مكان بناء الإصدار الجديد. يحتوي Django وdirectory وidentity وaccess وترحيلاتها الجديدة، وخدمات هوية وصلاحيات وفروع وتدقيق، وواجهة ERP عربية متجاوبة لإدارة الأعضاء والفروع والأدوار والدعوات والتدقيق. لا واجهات بيع بعد.

حُسمت حدود الشركات والمستخدمين في ADR 0003: لكل شركة مخططها وحساباتها وجلساتها، ولا حساب متعدد الشركات. أُنشئ PostgreSQL مستقل واجتاز الأساس اختبارات R03 محليًا وعلى GitHub Actions. لا تنسخ ملفات .env أو media أو migrations من النسخة المرجعية. أدلة الاختبارات الفعلية وحدودها في TEST_LOG.md، ومصفوفة ACCESS_VERIFICATION.md تضم ما تبقى للمراحل اللاحقة.

اختبارات السياسة من جذر المستودع: `python -m unittest discover -s rebuild/tests -v` بمفسر Python صالح. لا تثبت وحدها عزل البيانات الفعلي.

راجع `../docs/rebuild/PLAN.md` و`../AGENTS.md` قبل البدء.

دليل الإعداد والأوامر: `../docs/rebuild/RUNBOOK.md`. اعتماديات Python في pyproject.toml وpdm.lock فقط؛ بيئة التطبيق .venv، والأسرار المحلية .env مستبعدة.

SMTP اختياري مع سجل انتظار وعامل خلفية `pdm run mail-worker` عند إعداده؛ راجع RUNBOOK وADR 0006. `pdm run test-browser` يفحص الواجهة عبر Chromium ببيانات صناعية.

R06 تضيف clinical للعملاء والفحوص والوصفات وإصدارات التصحيح وصورة فحص اختيارية خاصة؛ راجع ADR 0007. اختبارات إغلاق R06 كانت67 Django/PostgreSQL و44 سياسة و7 متصفح، ونجح CI للـcommit c486202 (T016). التالي R07.

R07 تضيف catalog للمنتجات والمتغيرات والأسعار SAR قبل الضريبة بقواعد صريحة للنطاق والكمية والتاريخ؛ راجع ADR 0008. الإجمالي المحلي الحالي143 حالة (89 Django و44 سياسة و10 متصفح)، ونجح CI للـcommit b2b550f (T018). التالي R08.

R08-M01 تضيف مصفوفات العدسات المخزنية وإضافة بمعاينة وتوقيع ومنع تكرار وعكس مستقل. نجح166 اختبارًا محليًا وعلى CI (T022)؛ اكتملت M01 وتبقى بقية R08 للحجز/الصرف والتحويل/الجرد والدفعات/التسلسلات. راجع ADR 0009 وR08_CHECKLIST.

R08-M02 تضيف الحجز والصرف والتحرير الجزئي وإلغاء المتبقي وعكس الصرف المحفوظ. نجحت182 حالة فريدة محليًا وعلى CI42681586976 (T024/T026)؛ اكتملت M02 وتبقى R08 in_progress. التالي M03 للتحويل والجرد ثم M04 للتتبع. راجع ADR 0010 وR08_CHECKLIST.

R08-M03 تضيف التحويل الفوري بإذن الفرعين، والجرد بإصدار متوقع والعكس المحفوظ. نجحت200 حالة فريدة محليًا وعلى CI42700119188 (T028/T029)؛ اكتملت M03 وتبقى R08 in_progress. التالي M04 للأصناف المخزنية المتبقية والدفعات/الصلاحية والتسلسلات. راجع ADR 0011 وR08_CHECKLIST.

R08-M05 تضيف معاينة وطباعة ملصقات الباركود وحماية من تعارض SKU/باركود جديد. نفذت قبل M04 بطلب المستخدم؛ نجحت211 حالة كاملة على CI42750090649 (T033)، مع اختبارات محلية موجهة T030 وتعذر الإعادة المحلية الأخيرة T032 بسبب Docker. اكتملت M05 وتبقى M04 التالية، وR08 in_progress؛ الأجهزة الفعلية لم تعاير بعد. راجع ADR 0012 وR08_CHECKLIST.

R08-M04 تضيف استلام الإطارات والملحقات والعدسات، ودفعات اللاصقة وصلاحيتها والوحدات التسلسلية للأجهزة، مع حجز ونقل وجرد وعكس بالهوية نفسها وسجل فرع تاريخي. القرار ADR 0013 ومعايير R08_CHECKLIST؛ قيد التحقق النهائي قبل إغلاق R08. عاد Docker المحلي بعد T032 دون استخدام قاعدة legacy.

اكتملت R08 بكل M01–M05 وفق T035/T036، مع228 حالة كاملة على CI42767528416 للـcommit1133eb8. المخزون يدعم الإطارات والملحقات ودفعات اللاصقة وصلاحيتها ووحدات الأجهزة التسلسلية، والمصفوفة والحجز والصرف والنقل والجرد والعكس والملصقات. التالي R09 لنواة المحاسبة؛ لا ترحيل أو تقييم مالي ضمن R08.

R09-M01 قيد التحقق: ملف البائع القانوني والضريبي داخل مخطط الشركة بإصدارات محفوظة، مع قائمة نواقص وحالة ربط غير مفعل. نجح التحقق المحلي الموجه T039؛ ينتظر إغلاق M01 نتيجة CI. تفاصيل مسؤوليات الضريبة والفواتير والربط في ADR 0014 وR09_CHECKLIST وzatca/REVIEW، والفجوات الرسمية لا تستبدل بمحاكاة.

اكتملت R09-M01 وفق T039/T040، مع238 حالة كاملة على CI42805028665 للـcommit806b814. الملف الضريبي الأولي له إصدارات محفوظة ونواقص واضحة، والربط/الإصدار غير مفعل. R09 تبقى قيد التنفيذ؛ التالي M02 لدليل الحسابات والفترات. لا يدعي نجاح الاختبارات امتثالًا أو ربطًا أو صحة تسجيل منشأة.

R09-M02 قيد التحقق النهائي: دليل حسابات هرمي وفترات غير متداخلة وإغلاق وإعادة فتح، بهويات ثابتة وسجل عمليات وصلاحيات ledger. التحقق المحلي الموجه T042 نجح؛ الإغلاق ينتظر CI. ADR 0015 ومعايير R09_CHECKLIST، ولا ترحيل قيود حتى M03.

اكتملت R09-M02 وفق T042/T043، مع252 حالة كاملة على CI42811623939 للـcommit23ca02b. دليل الحسابات والفترات وتاريخ التغييرات جاهزة ضمن هذا النطاق؛ R09 تبقى قيد التنفيذ. التالي M03 للقيود والترحيل والعكس وبوابة معالجة الفترة غير المستخدمة. لا قيد مرحل أو رصيد افتتاحي أو اتصال هيئة منفذ بعد.

R09-M03 قيد التحقق النهائي: مسودات قيود يدوية SAR بإصدارات وترحيل متوازن ثابت وعكس مستقل، مع حراس PostgreSQL وصلاحيات فروع وإلغاء فترة غير مستخدمة. نجح التحقق المحلي T045؛ الإغلاق ينتظر CI. المرجع ADR 0016 وR09_CHECKLIST. الموازين والمطابقة M04، ولا فاتورة أو ضريبة أو اتصال هيئة تلقائي من القيد اليدوي.

اكتملت R09-M03 وفق T045/T046؛275 حالة كاملة على [CI](https://github.com/Elhussin/osm/actions/runs/42863298461) للـcommit dbd459d045fcbef144cf1ef8ff1dd796f59cc289. تشمل المسودات بإصدارات والترحيل المتوازن والعكس وإلغاء الفترة غير المستخدمة. التالي R09-M04 لدفتر الحسابات وميزان المراجعة والمطابقة؛ R09 تبقى قيد التنفيذ. لا اتصال هيئة أو ترحيل تلقائي لفاتورة أو مخزون من هذا الجزء.

R09-M04 قيد التحقق: /finance/reports/trial-balance/ و/finance/reports/ledger/ لميزان المراجعة والمطابقة ودفتر الحساب. ADR 0017 يحدد النطاق واللقطة ودقة المجاميع؛ لا ترحيلات جديدة أو كتابة من التقرير.
