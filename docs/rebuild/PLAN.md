## متطلبات أكدها المستخدم بعد الحصر
- نقطة البيع متصلة بالإنترنت في الإصدار الأول؛ اختيار الطابعة وقارئ الباركود مؤجل، ولا يمنع بناء التدفق العام.
- وصيل هو مزود التأمين المستهدف لجلب بيانات العميل والأهلية والموافقات ورفع المطالبات. يمكن تنفيذ الخطوات الداخلية في R12 قبل توفير API والمفاتيح؛ الربط الفعلي R13 بعد الوثائق والاختبار. راجع INSURANCE_WORKFLOW.md. لا نفترض دعم التسوية لدى المزود دون وثائق.
- استلمت حزمة وصيل v2 وPostman وراجعت في waseel/REVIEW.md. ثبتت الأهلية وموافقة Vision والبحث والتواصل والإلغاء؛ عقد رفع المطالبات والجلب المستقل غير موجودين بوضوح. فجوات W01–W07 تمنع اعتماد اتصال مكتمل، ولا تمنع متابعة R02. اختبارات الاستخراج محلية وليست اختبارات أعمال R12/R13.
- أكد المستخدم في R02 أن كل حساب يتبع شركة واحدة فقط. اعتمد ADR 0003: مخطط لكل شركة يتضمن المستخدمين والجلسات والأدوار، ودليل شركات ونطاقات في public. لا حساب متعدد الشركات أو مشاركة جلسة بين نطاقاتها.

- اختار المستخدم تسليم دعوات الموظفين عبر SMTP عند إعداده. يبقى النسخ اليدوي متاحًا لحين الإعداد، ولا تُستخدم بيانات بريد حقيقية في الاختبارات.

- طلب المستخدم صورة اختيارية لفحص النظر في R06؛ تطبق عليها صلاحيات الوصفة نفسها، دون OCR أو اشتراط الصورة لحفظ القياسات. راجع ADR 0007.

- طلب المستخدم إدخال وعرض مخزون العدسات بمصفوفة تجمع الصنف. قُسمت R08 إلى R08-M01 للمصفوفة والإضافة والعكس، ثم R08-M02 للحجز/الصرف وR08-M03 للتحويل/الجرد وR08-M04 للدفعات/الصلاحية والتسلسلات. التفاصيل في ADR 0009 وR08_CHECKLIST؛ لا إغلاق كامل R08 بإكمال المصفوفة وحدها.

## التدرج في الاستبدال
- نبدأ في `rebuild/` دون نسخ المشروع القديم بالكامل. لا نستخدم migrations القديمة كأساس جديد.
- تُراجع كل قاعدة عمل قبل نقلها: احتفاظ بالمعرفة، إعادة كتابة، أو استبعاد مع السبب.
- تُبنى اختبارات الوحدة والخدمات مع كل عملية، واختبارات PostgreSQL مع كل قيد أو معاملة، واختبارات المتصفح مع كل مسار مستخدم.
- لا تتحول شاشة أو وحدة إلى منجزة لمجرد اكتمال مظهرها. يلزم نجاح الصلاحيات ومسار الفشل والبيانات المرتبطة.
- يُحذف الملف المرجعي عند انعدام الحاجة إليه وإثبات بديله، أو ثبوت أنه أداة مستبعدة بلا استخدام. توثق العملية في CLEANUP.md.
- لا توجد مدة زمنية معتمدة قبل حصر R01. الترتيب يوضح الاعتماد؛ أي تغيير فيه يسجل مع السبب.
