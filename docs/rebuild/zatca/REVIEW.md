# مراجعة ZATCA — الاستعداد والحدود

متابعة2026-11-11 لـR10-M03: راجعت قواعد مبالغ وفئات مختارة في XML Standard v1.2 وقاموسه؛ الخريطة والبصمات والنطاق في CALCULATION_RULES.md وSOURCES.json. نفذ حساب ومعاينة داخلية قيد التحقق، دون XML/SDK/توقيع/QR/إرسال. وصف غياب المحرك أدناه يخص خط أساس M01 السابق؛ Z01 جزئية وتحتاج قواعد المستند الكامل والتحقق عند M05/R13، وZ02–Z06 تبقى مفتوحة. لم تعتمد مصفوفة الأصناف الفعلية أو صحة تسجيل المنشأة.

تاريخ المراجعة2026-11-10، ومتابعة إتاحة الملفات2026-11-11. الاسم الحالي: هيئة الزكاة والضريبة والجمارك. طلب المستخدم ربطها ومتطلباتها أثناء الإعداد؛ هذا السجل يميز التنفيذ المحلي عن الإثبات الرسمي. لا بيانات منشأة حقيقية أو بيانات اعتماد مستخدمة.

ZS02: الفصل6.4 يفرق بين اعتماد الفاتورة الضريبية قبل مشاركتها والإبلاغ عن المبسطة خلال24 ساعة من توليدها؛ لذلك لا يكفي إرسال خلفي واحد لكل الأنواع. الفصل4.3 يغطي الإشعارات، والفصل6.5 الممنوعات، والفصل7.3 الحفظ. يتعين تحويلها لقواعد واختبارات قبل الإصدار. ZS03 الفصل3 يحدد previous invoice hash، والفصل4 محتويات QR والفصل2 الشهادات والختم. باركود SKU الحالي للمخزون لا يؤدي أيًا من وظائف QR الفاتورة.

تعذر جلب PDF الخاص بـXML Standard عبر أداة الويب مرتين في10 نوفمبر (timeout)، رغم قراءة صفحة ZS01 الرسمية. يحفظ هذا التعذر التاريخي؛ نجح جلب PDF والرابطين الرسميين في11 نوفمبر. [سجل المصادر والبصمات](SOURCES.json) يثبت النسختين وحجمهما وSHA256 ونطاق الاطلاع، والملفان المحليان في cache مستبعد من Git. تحديث الصفحة المعروض12 يناير2026 لا يعني إصدارًا جديدًا للمواصفة. تعذرت قراءة XLSX بأداة الويب ثم قرئت المقدمة وعناوين القاموس فقط بأداة الجداول المرفقة، دون تعديل/تصدير وببصمة مطابقة بعد القراءة. لم تراجع صفوف القاموس وأمثلته أو عقد API أو أدوات SDK أو كل قواعد/أمثلة XML للحساب بعد؛ لا ندعي استكمالها أو نختلق أمثلة. لم تنزل مكتبة خارجية لتقوم مقام مواصفات الهيئة، وتبقى مراجعة الإصدارات قبل بوابة التكامل مطلوبة.

## حالة المنتج
M01 يبني ملف بائع أوليًا بإصدارات وقائمة نواقص وحالة غير متصل فقط. لم ينفذ محرك VAT أو فاتورة أو XML أو توقيع أو QR فاتورة أو SDK أو اتصال بالهيئة. لا يوجد endpoint إرسال إنتاج. اكتمال الحقول المحلية لا يثبت التسجيل الصحيح أو المطابقة أو الربط. لا نشر لبادج «معتمد من الهيئة»، ولا ربط بإقرار أو حساب زكاة تلقائي من هذا العمل. مصدر أدلة الاختبارات المنفذة TEST_LOG، وإغلاق كل بوابة مستقل في STATUS.
