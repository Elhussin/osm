# R04 — المخرجات والتدرج

آخر تحديث: 2026-11-09. نتائج التشغيل النهائية في TEST_LOG.md؛ لا يُغلق بند بمجرد وجود ملفه.

| الجزء | التنفيذ | بوابة الاختبار |
|---|---|---|
| R04.1 إنشاء الشركة | domain lock، reservation، مفتاح retry، schema داخلي، مالك وفرع أول، ready/failed | إعادة محاولة بلا تكرار مالك/تغيير كلمة مرور، فشل بلا domain واستئناف بنفس الشركة |
| R04.2 العضويات | فروع وقوالب أدوار وتعيينات ووصول فروع، resolver من DB | قيد نطاق الدور، المنح خارج امتياز المنفذ، سحب الدور/الوصول أثناء session، تعطيل الحساب |
| R04.3 الملكية | قفل شركة داخلي ومعاملة وإعادة مصادقة | آخر مالك محمي، بديل نشط، طلبان متزامنان ينفذ أحدهما فقط |
| R04.4 HTTP والجلسات | login/logout/branch selection، no-store، host/session binding، CSRF/throttle | كلمة مرور/cookie شركة A لا تدخل B، لا public auth، تزامن طلبات، أعلام cookie، CSRF حقيقي |
| R04.5 الدعوة/الاستعادة | إصدار داخلي مخول ورمز موقع + digest وانتهاء واستخدام واحد | شركة/غرض خاطئ، انتهاء، تكرار، منع مسؤول أدنى من إعادة كلمة مرور مالك، إلغاء الجلسة بعد reset |
| R04.6 التدقيق/التكامل | AuditEvent منقح append-only للـruntime، إعداد ProviderConnection وtask boundary | UPDATE/DELETE ممنوعان بدور DB محدود، لا أسرار في الأحداث، صلاحية المزود مستقلة، استعادة سياق المهمة |

## ما ينتقل إلى المراحل التالية
- R05: نظام التصميم والتجربة المتجاوبة، شاشات إدارة الأعضاء والفروع والأدوار الثابتة، تسليم روابط الدعوات عبر قناة معتمدة وتجربة الاستعادة. لا محرر أدوار مخصص أو صلاحيات حرة قبل قرار واختبار منفصلين.
- R06/R08/R10: تطبيق نفس الحدود على ملفات العملاء والوصفات والمخزون والمبيعات، بما فيه التصفية قبل البحث والتصدير وعدد السجلات.
- R13: queue فعلية وموصل وخزان أسرار وعقد API وصيل؛ النموذج الحالي ليس اتصالًا مكتملًا.
- R14: إنتاج ومراقبة وسياسة احتفاظ بـthrottle/audit وقياس الأداء والاستعادة. لا ادعاء جاهزية إنتاج.

## التنظيف
لا imports من osmBack أو osmFront في التنفيذ الجديد. تبقى ملفات الهوية القديمة مرجعًا لأن بعض محتواها (صفحات وإعدادات وHR واشتراك SaaS) لم ينقل بعد؛ حذفها الآن سيخفي معرفة لم تحصر بالبديل. لا حذف migrations قديمة أو تغيير حصر legacy في هذه المرحلة.
