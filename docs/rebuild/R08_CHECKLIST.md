# تدرج R08 — المخزون

لا تُغلق R08 لمجرد نجاح مصفوفة الإضافة. الحالة التفصيلية في STATUS.json والأدلة في TEST_LOG.

| الخطوة | النطاق | بوابة التحقق |
|---|---|---|
| R08-M01 | مصفوفة العدسات المخزنية وعائلات الصنف والرصيد والإضافة والعكس | تفويض وقيود ومعاملة كاملة وidempotency وتزامن وصلاحيات DB ومتصفح وصور QA |
| R08-M02 | حجز وصرف وتحرير وإلغاء | آخر وحدة بطلبين، عدم حجز/صرف مرتين، عكس محفوظ، role revocation |
| R08-M03 | تحويل وجرد ومطابقة الحركات | صلاحية المصدر والوجهة، منع السالب، جرد مع توقع الإصدار، rollback وعكس |
| R08-M04 | دفعات وصلاحية اللاصقة وتسلسلات الأجهزة | هوية وتواريخ وتتبع وعدم صرف منتهي أو تكرار serial، مصفوفة أبعاد مناسبة إن لزمت |
| R08-M05 | معاينة وطباعة ملصقات الباركود | قيمة صحيحة لكل متغير، عزل وصلاحيات، عدد نسخ محدود، قراءة مستقلة للرمز، وتنسيق طباعة مختبر |

## قبول المصفوفة R08-M01
- SPH صفوف وCYL أعمدة بخطوة0.25 ونطاق حتى400 خلية، وفصل الوحدة/المادة/index/القطر/التصميم/اللون/الطلاءات.
- رصيد branch-local قبل العدّ/الlookup، وصفر لمتغير موجود بلا رصيد وشرطة للمتغير غير المعرف. إجمالي العائلة واضح أنه يشمل خارج نافذة القوى.
- إضافة للموجود فقط أو إنشاء الناقص بصلاحية catalog.manage وموافقة صريحة، دون إنشاء لخلايا فارغة/صفرية أو تعديل أسعار الموجود.
- لصق block من Excel رفضه atomic على الواجهة عند خطأ، ورفض الخادم للكميات السالبة/الكسور/الخلايا المكررة أو خارج النطاق.
- معاينة بلا أثر، تعديل دون فقد البيانات، توقيع actor/company بمدة محدودة، وإعادة تحقق عند التأكيد.
- مستند/حركات/أرصدة/متغيرات جديدة داخل معاملة؛ rollback بعد فشل الحركات، مفتاح طلب يرفض محتوى مختلفًا، وطلبان متزامنان لا يكرران الأثر أو يفقدان الزيادة.
- عكس مستقل وأحادي، يحفظ الأصل ويرفض الكمية المستخدمة/المحجوزة، وruntime يمنع تغيير/حذف المستندات والحركات وهوية المصفوفة.
- backfill يحفظ الهوية والسعر السابقين، وقيود DB غير سالبة ومتسقة وجداول inventory غائبة من public.
- Chromium فعلي للحافظة والتنقل والمعاينة/التعديل/الاعتماد/العكس، وهاتف390/768/1440 وتمرير الجدول دون overflow عام، وحفظ دون JavaScript، ومنع مستخدم الشركة/الفرع غير المخول.

بعد R08-M01 التالي R08-M02؛ ليس R09. لا تُعد المحاكاة المباشرة لرصيد محجوز تنفيذًا للحجز.

## قبول الحجز والصرف R08-M02
- حجز للعدسات المخزنية النشطة بوحدة وفرع محددين، دون تجاوز المتاح؛ المتبقي + المصروف + المحرر = الأصل.
- صرف وتحرير جزئيان؛ إلغاء المتبقي يحفظ المصروف ويمنع صرفًا جديدًا. إيقاف الكتالوج يمنع الصرف مع السماح بتحرير الأثر السابق.
- أحداث لا تعدل، إصدار متوقع ومفتاح طلب وبصمة؛ تكرار مطابق يعيد النتيجة وتغيير المحتوى/الإصدار يرفض دون أثر.
- عكس صرف كامل الحدث مرة واحدة للمالك، يعيد المتاح دون حجز تلقائي حتى بعد إلغاء المتبقي، ويحفظ الأصل والحركة المقابلة.
- تنافس على آخر وحدة، وعلى الصرف مقابل التحرير، وعلى إعادة الصرف/عكسه بالمفتاح نفسه. فشل الحركة أو التدقيق يتراجع عن الحدث والرصيد والحجز.
- خدمات تتحقق من الشركة والفرع والدور الحالي حتى عند replay؛ لا وصول تلقائي لقارئ الكتالوج، ولا تعديل هوية الحجز/أحداثه بدور runtime.
- HTML/CSRF وطلب كمية أكبر/إصدار قديم وفرع/شركة أخرى، ومتصفح فعلي مع وبدون JavaScript، وانعكاس المتاح الحقيقي في المصفوفة.
- الدليل المحلي وCI في TEST_LOG، والقرار ADR 0010. تبقى R08-M03/M04 منفصلتين، ولا يوجد ربط مالي أو طلب بيع أو انتهاء تلقائي للحجوزات.

## قبول التحويل والجرد R08-M03
- نقل الصنف والوحدة نفسيهما بين فرعين مختلفين مع إذن وقراءة الطرفين، وحركتين متوازنتين ورصيد وجهة ينشأ ذريًا عند غيابه.
- نقل المتاح فقط وحماية المحجوز؛ مستند التحويل غير مرئي إذا غابت قراءة أي طرف، قبل limit والعدّ والlookup.
- جرد مطلق لرصيد قائم مع expected_version منذ فتح الشاشة، ورفض التغير اللاحق أو كمية أقل من المحجوز. الصفر صالح، والقراءة المطابقة تحفظ مستندًا وترفع الإصدار دون حركة صفرية.
- stock.count للمالك ومدير الفرع؛ لا اعتماد جرد أو عكس لموظف المخزون أو قارئ الكتالوج، ولا تجاوز بعلم superuser.
- replay مطابق بعد إعادة التفويض، ومحتوى/إصدار مختلف يرفض. تنافس النقل والجرد، وتكرار التحويل وعكسه، وفشل الحركة/التدقيق دون أثر جزئي.
- عكس محفوظ أحادي؛ النقل لا يستهلك محجوز الوجهة، والجرد لا يعكس بعد عملية رصيد لاحقة؛ لا حذف مستند أو عكس عكس.
- ترحيل تاريخ M01/M02 مع branch محفوظ لكل حركة ودون تغيير أرقامها/لقطتها، وقيود مصدر واحد ومنح runtime تمنع تغيير/حذف المستندات والحركات.
- HTML/CSRF ووجهة مزورة وفرع/شركة أخرى، وChromium لسطح المكتب والتحويل/الجرد/العكس وهاتف390 دون JavaScript وجرد صفري. لا إغلاق M04 أو ربط مالي أو تحويل شحن/استلام مؤجل.

## بوابة النطاق المتبقي R08-M04
قبل إغلاق R08 يلزم تغطية الأصناف المخزنية الأخرى من الكتالوج أيضًا: الإطارات والملحقات بوحداتها، واللاصقة بدفعات وصلاحية إلزاميتين، والأجهزة بوحدة تسلسلية لكل قطعة. تختبر الإضافة والحجز والصرف والتحويل والجرد والعكس لكل نوع؛ RX والخدمة خارج الرصيد وفق ADR 0008. اكتملت M04 وفق T035/T036، وأغلقت R08 بجميع خطواتها M01–M05. التالي R09، دون ربط مالي ضمن إثبات المخزون الحالي.

## قبول التنفيذ R08-M04
- استلام عام للإطارات والملحقات والعدسات بوحداتها الثابتة، واستبعاد RX والخدمة؛ لا أثر جزئي عند فشل الحركة/التدقيق.
- دفعة اللاصقة مرتبطة بمتغير وصلاحية ثابتة، ورصيدها مستقل لكل فرع؛ لا تاريخ بديل للدفعة نفسها أو دفعة منتهية عند الاستلام.
- رقم تسلسلي فريد لكل الشركة لكل جهاز، كمية0/1 وصف واحد يتنقل بين الفروع، دون إعادة استخدام هوية مصروفة أو حذفها.
- حجز/صرف من position صريح صحيح النوع/الصنف/الفرع؛ منع المنتهي عند الحجز والصرف اللاحق، والسماح بتحرير/عكس الأثر السابق. الصالح للصرف مختلف عن الفعلي المنتهي.
- نقل نفس الدفعة/الوحدة وحماية المحجوز، وعكس لا يستهلك هوية أخرى ولو كفى الإجمالي؛ صلاحية وقراءة الفرعين.
- جرد الهوية بإصدار الإجمالي والموضع منذ فتح الشاشة،0/1 للتسلسل، ومنع الأقل من المحجوز والعكس بعد حركة لاحقة. لا إعادة توزيع أو قوى/وحدة مستنتجة.
- مطابقة StockBalance مع الحركات والحجوزات وتفصيل StockPosition، وقيود/منح PostgreSQL تمنع السالب والتكرار وتعديل الهوية أو حذف السجل.
- تزامن آخر وحدة من دفعة، وتسلسل متكرر ومفتاح مطابق، وrollback يشمل المستند والهوية والإجمالي والتفصيل؛ replay قديم دون تتبع يظل متوافقًا.
- ترحيل يحفظ التاريخ ويرفض رصيدًا متتبعًا قديمًا بلا mapping مراجع، دون اختلاق هويات أو حذف بيانات.
- HTML/CSRF وشركة/فرع/موضع مزور، وسجل تاريخ مصفى بفرع الحركة حتى بعد نقل التسلسل، وChromium لمسار الدفعة والهاتف دون JavaScript للإطار والجهاز والمنتهي وأكواد طويلة.

## قبول ملصقات الباركود R08-M05
- طباعة لصنف مخزني نشط ومتغيره: الباركود المسجل أولًا وإلا SKU نفسه؛ لا اختراع GTIN أو تغيير هوية أو رصيد أو سعر.
- رفض قيمة تطابق SKU/باركود متغير آخر، ومنع إدخال تعارض جديد عبر الكتالوج أو إنشاء المصفوفة، ورفض قيمة/عدد/قالب غير صالح؛ لا قص الرمز أو ضغط عرضه لتجاوز حدود الملصق.
- Code128 محلي SVG دون شبكة أو خدمة صور خارجية؛ اسم الصنف وSKU والوحدة ومواصفات تمييز مختصرة، دون أسعار خاصة أو مرضى.
- عدد نسخ1–120 وقالب A4 عادي أو عريض واختيار تلقائي؛ معاينة ونداء طباعة صريح، مع عمل المعاينة دون JavaScript والطباعة من أمر المتصفح.
- catalog.read حي داخل الشركة، ورفض شركة أخرى وسحب الدور وCSRF؛ لا تفويض من بيانات المتصفح أو وصول stock ضمني.
- قراءة الرمز الناتج ببرنامج مستقل، ومتصفح فعلي مع print media وقياسات الملصق وفصل الصفحات وإخفاء أدوات التحكم. معايرة الطابعة/القارئ الحقيقيين تبقى مؤجلة لاختيار الأجهزة، ولا يدعي الاختبار طباعة ورقية فعلية.
