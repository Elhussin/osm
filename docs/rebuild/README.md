## قواعد التحديث
تفاصيل تقارير M04 في [ADR 0017](decisions/0017-ledger-reports.md) ومعايير R09_CHECKLIST؛ الأرقام مقيدة بفروع القراءة قبل التجميع، ولا تعتبر مطابقة الأسطر شهادة ضريبية.

لكل جزء معرّف ثابت، وتبعيات، ومخرجات، واختبار قبول. الحالات: pending / in_progress / blocked / done.
لا يُغلق جزء قبل نجاح الاختبارات المرتبطة به. يسجل الفشل أو تعذر التشغيل كما حدث، ولا يستبدل الاختبار بوعد بتنفيذه لاحقًا.
تُحدّث الحالة والخطة وسجل الاختبارات والتغيير عند نهاية كل مهمة. تُضاف القرارات الجديدة كملفات مرقمة، مع سبب القرار وآثاره وطريقة التحقق منه.

## حدود الاستقلال
العمل يتم داخل هذه النسخة؛ لا يُعدّل المشروع الأصلي أو قواعد بياناته. تحقّق الاستقلال التشغيلي بقاعدة ومستخدم وأسرار ووحدة تخزين خاصة في R03. أكد المستخدم نقل الكود لمستودع جديد؛ origin يشير إلى https://github.com/Elhussin/osm.git. أذن المستخدم بالـcommit والدفع إلى codex/r03-foundation في 2026-11-09؛ نجح CI ولم يدمج الفرع في main. لا إعادة كتابة لتاريخ المستودع أو تعديل لقواعد legacy.
تُستخدم بيانات صناعية للاختبارات. نقل بيانات حقيقية مرحلة منفصلة تتطلب خريطة تحويل ومطابقة وتجربة رجوع.
