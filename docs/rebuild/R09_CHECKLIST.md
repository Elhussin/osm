# R09 — المحاسبة والتهيئة الضريبية

المرجع ADR 0014؛ تعتمد R08 المكتملة. لا يغلق R09 بإكمال نموذج إعدادات أو قائمة متطلبات.

اكتملت M01 وفق T039/T040 وM02 وفق T042/T043 وM03 وفق T045/T046؛ أحدث تحقق كامل275 حالة على CI42863298461. التالي M04 لدفتر الحسابات والموازين والمطابقة. لا اختبار SDK أو بيئة الهيئة ضمن هذه الأدلة.

| الخطوة | المخرج | يعتمد على | الحالة المرجعية |
|---|---|---|---|
| R09-M01 | ملف البائع الضريبي بإصدارات واستعداد ZATCA غير مفعل | R08 | STATUS.json |
| R09-M02 | دليل حسابات وفترات مالية وصلاحياتها | M01 | STATUS.json |
| R09-M03 | قيد متوازن، ترحيل ذري أحادي وعكس، منع التعديل والفترة المغلقة | M02 | STATUS.json |
| R09-M04 | واجهات ERP وميزان مراجعة ومطابقة واختبارات كاملة | M03 | STATUS.json |

## قبول M01
- ملف داخل مخطط الشركة فقط، ونسخ سابقة ثابتة لا تعاد كتابتها. العملة SAR والدولة SA دون تفعيل ضريبة مفترض.
- التسجيل غير محدد افتراضيًا، رقم VAT المسجل15 رقم ASCII، وغير المسجل لا يحمل رقمًا. يسمح حفظ عنوان أولي ناقص وتظهر النواقص.
- company.manage حي، ولا تجاوز superuser أو مسؤول ربط منفرد؛ عزل شركتين وقبل حد التاريخ وCSRF.
- قفل ومعاملة وإصدار متوقع، replay مطابق مع إعادة تفويض، ورفض محتوى مختلف وتنافس إصدار وتراجع كامل عند فشل التدقيق.
- PostgreSQL يثبت وحدانية الإصدار/المفتاح والقيود والمنح التي تمنع تعديل/حذف النسخ؛ لا SQLite كدليل.
- لا إرسال أو إصدار ضريبي عند اكتمال الملف، أو POST يزعم connected/compliant؛ الحالة مشتقة في الخادم ولا تحفظ flags من المستخدم.
- متصفح RTL لسطح المكتب والهاتف دون JavaScript، وتصحيح نسخة مع بقاء الأصل وعرض حالة الربط غير المنفذ.
- سجل مصادر رسمية وفجوات وتوزيع مسؤوليات R09/R10/R13؛ لا ادعاء SDK/sandbox من اختبارات محلية.

## قبول M02
- حسابات بتصنيف وطبيعة صريحين، ومجموعة/حساب ترحيل، وأب نشط من التصنيف نفسه وعمق8 كحد أقصى. هوية ومسار ثابتان؛ لا seed أو أرصدة افتتاحية مفترضة.
- تسمية وتعطيل/تفعيل بإصدار متوقع وسبب وسجل قبل/بعد؛ لا تعطيل مجموعة ذات ابن نشط أو تفعيل ابن لأب معطل.
- فترات تشمل يوم البداية والنهاية، وتسمح بالتجاور وتمنع التداخل حتى مع المغلق، بقيد PostgreSQL فعلي وطلبات متزامنة. لا إعادة كتابة للرمز/الاسم/التواريخ.
- إغلاق وإعادة فتح مع حفظ الانتقالات وإصدار متوقع؛ سباق إغلاق/ترحيل قيد يبقى لاختبارات M03 عند تنفيذ الترحيل.
- ledger.read للقراءة وledger.post أيضًا للكتابة؛ لا company_admin أو superuser أو دور فرع بلا تفويض محاسبي. النطاق إعدادات شركة دون أرصدة فروع.
- replay مطابق يعاد تفويضه، ومحتوى مختلف/إصدار قديم يرفض، وrollback يشمل الكيان والعملية والتدقيق، ومنح runtime تحمي الهوية والتاريخ من SQL العادي.
- عزل شركتين وlookup/خيارات/count وCSRF وPOST مزور، وترحيل يحفظ الملف الضريبي الموجود، ومتصفح للهاتف دون JavaScript وسطح المكتب.

## قبول M03
- مسودات بفرع ثابت وإصدارات محتوى محفوظة،2–40 سطرًا بحسابات ترحيل، ومبالغ SAR دقيقة بمنزلتين دون float أو قيم خاصة/تقريب إدخال زائد. يمكن مراجعة غير المتوازن دون أثر دفتر.
- ترحيل مرة واحدة بعد إعادة التحقق من التوازن والحساب والأجداد والفترة المفتوحة والوصول للفرع؛ رأس وأسطر ولقطات حسابات ثابتة ورقم محاسبي مستقل عن رقم الفاتورة.
- PostgreSQL يرفض رأسًا بلا أسطر أو مجموعًا غير مطابق عند commit، وسطرًا ذا جهتين/صفر/سالب، ويحمي المسودة النهائية والهويات والقيود والعمليات تحت runtime. لا يثبت ذلك حماية من DBA.
- عكس كامل وأحادي بقيد مستقل وتاريخ لا يسبق الأصل وفترة مفتوحة؛ قلب نفس الحسابات واللقطات ولو عطلت، وبقاء الأصل وعدم عكس العكس.
- مفاتيح تمنع التكرار مع إعادة تفويض قبل replay، وإصدار متوقع، وتزامن ترحيل/إلغاء وأرقام قيود وعكس وإغلاق/ترحيل وإلغاء فترة/إنشاء مسودة؛ rollback يشمل التسلسل والرأس والأسطر والحالة والتدقيق.
- إلغاء فترة بلا أي JournalRevision أو JournalEntry فقط؛ حالة void نهائية وسجل محفوظ ورمز ثابت، وإمكان فترة بديلة برمز جديد دون تعديل تاريخ مستخدم. الارتباط يبقى مانعًا ولو ألغيت المسودة.
- ledger.read/post ووصول فروع حي، وتصفية قبل lookup/count/بحث، وشركة/فرع آخر ودور مسحوب وsuperuser وCSRF وحقول مزورة. لا يمنح دور المحاسب وصول فروع تلقائيًا.
- ترحيلات إضافية تحفظ M01/M02، وواجهات بأسطر فعلية وإضافة صف دون DB، وتاريخ إصدارات وعمليات، وChromium للهاتف دون JavaScript وسطح المكتب.

## قبول M04 — قيد التنفيذ والتحقق وفق ADR 0017
- دفتر حساب وميزان مراجعة بتواريخ وفروع مصرح بها، وتطبيق التصفية قبل count والتجميع والصفحات؛ لا ledger.read عام بديلًا عن وصول الفرع.
- افتتاحي قبل بداية النافذة، وحركة مدين/دائن ضمنها وحدود شاملة، وختامي=افتتاحي+مدين−دائن بحساب Decimal دقيق. لا يحد إجمالي التقرير بسعة مستند واحد أو يحول إلى float.
- تضمين كل القيود المرحّلة والعكس كحركات مستقلة؛ لا إسقاط الأصل المعكوس أو المسودات إلى الدفتر، وبقاء الحساب المعطل الذي له تاريخ. طبيعة الرصيد لا تعكس إشارة حركة منشورة.
- الحساب ذو حركة يظل ظاهرًا حتى لو عاد رصيده إلى الصفر؛ خيار إخفاء الحسابات بلا نشاط لا يخفي أصلًا وعكسه. المجاميع العامة لا تجمع صفوف المجموعات الفرعية مرتين.
- أمثلة مرجعية مستقلة: مصروف في نوفمبر وعكسه في ديسمبر، وأرصدة افتتاحية محسوبة من القيود السابقة، وفرع غير مصرح ومسودة غير مرحّلة وحساب معطل، وتطابق المجاميع مع الأسطر المحفوظة.
- واجهات عربية متجاوبة وبحث/صفحات وتفاصيل مصدر آمنة، واختبارات PostgreSQL/HTTP ومتصفح للحدود والصلاحيات والمطابقة. لا ادعاء إقرار ضريبي أو حساب زكاة أو تقارير مالية معتمدة؛ التقارير والتصدير التشغيلي الأوسع R14.

## بوابة R09 الكاملة
اكتملت M03 وفق ADR 0016 وأدلة T045/T046، بما فيه مسار الفترة غير المستخدمة وترحيل القيود والعكس والتزامن. لا تصحيح بتاريخ SQL يدوي أو حذف تاريخ.

تبقى M04 مطلوبة لإغلاق R09: دفتر الحسابات وميزان المراجعة والمطابقة فوق القيود المنشورة في M03، مع الحفاظ على عزل الفروع والتوازن والتاريخ. تفصل حالة القيود عن الفواتير والضريبة والإرسال الخارجي. لا ربط تلقائي من save() أو حسابات/قيود مولدة بالحدس من legacy.
