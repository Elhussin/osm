# ADR 0006: واجهة الإدارة والبريد — R05

التاريخ: 2026-11-09. امتداد ADR 0001 و0003 و0005.

تطبيق workspace يجمع صفحات ERP المخصصة: نظرة عامة بأعداد فعلية حسب الصلاحية، أعضاء ودعوات وأدوار ثابتة وفروع ومستودعات وتدقيق ونقل ملكية. الهوية لكل شركة كما هي. جميع التغييرات عبر access.services مع إعادة فحص الصلاحية؛ إخفاء زر ليس تفويضًا. تعديل بريد صاحب صلاحية أعلى ممنوع لمن لا يستطيع تفويض أدواره، تجنبًا للاستيلاء عبر الاستعادة. الدعوة غير مقبولة لا تُفعّل إداريًا دون كلمة مرور.

HTML من Django مع CSS RTL وJavaScript صغير، وHTMX 2.0.11 محلي مرخص ومثبت البصمة. لا npm build أو عميل API لهذه الصفحات أو طلبات خطوط/CDN. البحث والتصفح والتنقل يستخدم HTML نفسه؛ تعطيل JavaScript يبقي النماذج الأساسية قابلة للاستخدام. dialog أصلي للهاتف وروابط تخطي وتركيز واضح وlabels. تطبيقات staticfiles/messages/workspace عديمة الجداول؛ جدول البريد داخل identity في مخطط الشركة فقط.

## البريد
اختار المستخدم SMTP عند إعداده. الوضع الافتراضي manual، ولا توجد مفاتيح SMTP أو رسائل حقيقية مستخدمة. وضع smtp يحتاج host/from صريحين وعامل mail-worker مجدول خارج خدمة الويب. إنشاء الدعوة/الرابط وإدراج سجل LinkDelivery يحدثان في معاملة واحدة؛ لا اتصال شبكة داخل الطلب أو قفل DB عبر SMTP.

العامل يحجز سجلًا بقفل skip_locked ثم يحرر المعاملة قبل الشبكة، بمهلة SMTP 10 ثوانٍ وحجز دقيقتين. يعيد المحاولة بتأخير تصاعدي وبحد خمس محاولات، ويلغي الرابط المستهلك أو المنتهي أو المستبدل أو البريد المتغير. الاستدعاء الدوري يستأنف الحجز المنقطع بعد مدته، ويغلق المحاولة الخامسة المنقطعة failed. مفتاح إدراج واحد لكل PasswordLink، وMessage-ID ثابت؛ لا يضمن SMTP إرسالًا مرة واحدة إذا انقطع الاتصال بعد قبول الرسالة وقبل تسجيل النجاح. إعادة إرسال المسؤول تصدر رابطًا جديدًا وتلغي القديم ولا تنشئ عضوًا جديدًا.

لا يحفظ سجل الانتظار الرمز أو nonce الخام؛ يحفظ مرجع الرابط والمستلم وعنوان الصفحة بلا fragment وحالة المحاولات. اشتقاق nonce عبر salted HMAC بمفتاح التطبيق ومعرفات الشركة/الرابط/العضو/الغرض يسمح للعامل بإعادة تكوين الرمز؛ digest فقط في PasswordLink. الروابط السابقة ذات nonce العشوائي تظل قابلة للاستهلاك. انتهاء الصلاحية يعتمد أيضًا على expires_at الثابت في DB، فلا تمدده إعادة التوقيع. تدوير SECRET_KEY يلغي الروابط المشتقة القديمة؛ لا تدّعِ الاحتفاظ بها بعد التدوير. المستلم بيانات شخصية داخل مخطط الشركة، وليس في audit أو stdout. عامل البريد عملية موثوقة تملك مفتاح التطبيق ويجب تشغيلها بحساب runtime فقط.

الاستعادة العامة تعرض جوابًا موحدًا للحساب الموجود وغير الموجود؛ تصدر فقط لحساب نشط له بريد وكلمة مرور، وبحد ثلاث محاولات لكل اسم/IP في 15 دقيقة. الدعوة/الاستعادة تستهلك عبر POST مع CSRF وتأكيد كلمة المرور، والرمز في fragment تمحوه الصفحة. Referrer-Policy same-origin ضروري لطلبات CSRF من المتصفح ولا يرسل إحالات للخارج؛ history cache في HTMX معطل وصفحات الشركة no-store.

## الإثبات والحدود
اختبارات PostgreSQL تشمل التفويض والعزل ومسارات البريد عبر locmem وفشل SMTP مصطنع والعاملين المتزامنين؛ Chromium يغطي التنقل HTMX والبحث والدعوة وقبولها ورفض الصلاحية والهاتف ولوحة المفاتيح والنماذج دون JavaScript. صور صناعية محلية داخل .tools المستبعدة. هذه ليست مراجعة WCAG شاملة أو اختبارًا لكل متصفح أو اعتماد SMTP إنتاج/وصيل/ZATCA. النشر النهائي وخدمة staticfiles وقياسات الحمل في R14.
