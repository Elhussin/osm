# ADR 0017 — دفتر الحساب وميزان المراجعة R09-M04

التاريخ2026-11-10. يعتمد ADR 0016؛ تقارير قراءة فقط داخل مخطط الشركة دون جداول أرصدة مخزنة أو ترحيلات جديدة أو تصدير عام.

ledger.read حي مع فروع visible_branches الصريحة والنشطة قبل التجميع والعد والصفحات. فرع محدد غير متاح يرفض ولا يتحول إلى كل الفروع؛ بلا وصول فروع تظهر أرقام صفرية دون كشف حركات. دليل الحسابات إعداد شركة، أما الأرقام فمقيدة بالفروع. لا امتياز superuser أو تغيير أدوار.

المصدر JournalEntry/JournalLine فقط. الأصل وعكسه مستقلان وفق تاريخ كل منهما؛ لا حذف الأصل من التقرير ولا قراءة المسودات. الحساب المعطل أو ذو رصيد صفري بعد حركة يبقى ظاهرًا. صفوف ميزان المراجعة لحسابات الترحيل ذات أسطر حتى نهاية المدة، دون صفوف مجاميع الشجرة التي تكرر المال. لا أرصدة افتتاحية مختلقة؛ الافتتاحي مجموع مدين−دائن قبل البداية، والحركة ضمن البداية والنهاية شاملتين، والختامي مجموع التاريخ حتى النهاية. طبيعة الحساب لا تقلب إشارة الرصيد.

التجميع PostgreSQL numeric غير مقيد بسعة مستند واحد، والعمليات المشتقة Decimal بدقة محلية60 دون float. يكفي ذلك سعة مبالغ الأسطر18 خانة مضروبة في سعة عد PostgreSQL bigint، دون اعتماد دقة Decimal العامة. عرض منزلتين. موجب الرصيد مدين وسالبه دائن؛ يعرض الميزان عمودين لكل رصيد. لا إخفاء للحسابات ذات حركة تساوت وعادت إلى الصفر.

كل تقرير أرقام من تعليمة PostgreSQL واحدة: ميزان المراجعة CTE يجمع رؤوس القيود والأسطر والأرصدة في لقطة واحدة، والدفتر CTE للافتتاحي والحركة وعدها والرصيد المتتابع والصفحة في لقطة واحدة. لا قفل كتابة/AccessLock من أجل قراءة تقرير ولا فصل استعلام الافتتاحي عن استعلام الأسطر أثناء ترحيل متزامن. اختيار صلاحيات الفرع قبل تعليمة التقرير كما في قراءة M03؛ المنح لا تحفظ في جلسة أو cache. أسماء الجداول من model metadata فقط، والمعاملات parameterized. لا عقد API خارجي جديد.

الميزان يجلب صفًا مجمعًا لكل حساب ذي تاريخ، ويقسمها20/صفحة في التطبيق؛ ليس تحميلًا لكل أسطر التاريخ، لكنه خط أساس يتناسب مع عدد الحسابات. بحث الرمز/الاسم يرشح صفوف العرض فقط؛ مجاميع المطابقة موسومة لكل النطاق المحدد وتبقى ثابتة عبر البحث والصفحات. دفتر الحساب يختار رمز حساب ترحيل مباشرة، ويعيد20 سطرًا فقط من PostgreSQL؛ الرصيد عبر الصفحات مرتب بالتاريخ ثم رقم القيد الفريد ثم موضع السطر. بيانات تسمية الدليل الحالية منفصلة عن لقطة اسم الحساب في سطر المصدر.

المطابقة تقارن مجاميع رؤوس القيود ضمن المدة مع مجموع أسطرها، وتوازن حركة المدين/الدائن وافتتاحي/ختامي كل النطاق؛ حالة الفروق لا تصلح تلقائيًا أو ترحل. لا تعني التطابق صحة تصنيف قيد أو إقرارًا ضريبيًا. إثبات PostgreSQL/HTTP ومتصفح ببيانات صناعية، مع مصروف نوفمبر وعكس ديسمبر والحساب المعطل والفرع المحجوب وتجاوز مجموع التقرير سعة مستند واحد. التقارير التشغيلية والتصدير والأداء واسع النطاق R14، والضريبة/الفوترة R10، وSDK/الاتصال R13.
