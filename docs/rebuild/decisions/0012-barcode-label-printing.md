# ADR 0012 — ملصقات باركود الأصناف R08-M05

التاريخ:2026-11-10. طلب المستخدم طباعة الباركود عند متابعة المخزون. أضيفت M05 مستقلة ونفذت قبل M04؛ الكتالوج وM03 مكتملتان، ولا تعتمد الطباعة على تغييرات الدفعات أو التسلسلات. تبقى M04 pending، ولا غلق R08 كاملة بالملصقات.

## الهوية والتفويض
الملصق لمتغير مخزني نشط، ويستخدم barcode المسجل إن وجد وإلا SKU الثابت. الرموز في الكتالوج ASCII مطبعة وفق ADR 0008. لا توليد رقم مصنع/GTIN أو تعديل SKU/باركود قديم أو تغيير سعر أو رصيد. يتحقق الخادم من أن القيمة لا تطابق SKU أو barcode لمتغير آخر داخل الشركة. خدمات إنشاء المتغير والمصفوفة ترفض تعارضًا جديدًا بين العمودين تحت AccessLock نفسه، بما في ذلك هوية صنف موقوف. قد توجد تعارضات تاريخية من قبل هذه الحماية؛ ترفض الطباعة دون تغيير رمز قديم تلقائيًا. PostgreSQL يفرض وحدانية كل عمود، والحماية العابرة بين العمودين في الخدمات؛ لا ادعاء قيد DB عابر أو حماية من SQL خارج الخدمات.

catalog.read يكفي لقراءة الملصق لأن بياناته من الكتالوج المشترك دون فرع أو رصيد أو تكلفة أو سعر عميل. يعاد التحقق عند POST؛ لا استثناء للـsuperuser ولا تبديل tenant من body. الطباعة قراءة دون أثر مخزني، ولا تسجل نجاح طابعة لا يمكن للخادم معرفته. صورة الرمز داخل استجابة tenant محمية no-store، ولا ملف عام أو cache مشترك.

## الإخراج
Code128 بواسطة python-barcode0.16.1 وSVG محلي داخل img data URI دون inline SVG غير موثوق أو خدمة شبكة. النص المقروء منفصل عن الخطوط ويطابق القيمة دون قص. quiet_zone6.5mm وmodule_width0.25mm وارتفاع12mm؛ المقاسات بداية قابلة للمراجعة مع الجهاز وليست اعتماد طابعة.

قالبان:90×43mm على A4 عمودي،12 ملصقًا/صفحة؛270×43mm على A4 أفقي،4/صفحة. هوامش10mm وفواصل محددة. اختيار auto يستخدم العادي إن اتسع الرسم وإلا العريض. رفض المقاس الضيق مع رسالة واضحة؛ لا تصغير غير مرئي للخطوط أو حذف محارف. عدد النسخ1–120، والمعاينة مقسمة إلى صفحات صريحة. الملصق يحتوي اسم المنتج وSKU ووحدة البيع ومواصفات تمييز مختصرة، دون سعر أو وصفة أو معلومات عميل. RX والخدمة خارج طباعة أصناف المخزون في هذه المرحلة.

CSS وJavaScript محليان؛ زر طباعة صريح وأمر طباعة المتصفح عند تعطيل JavaScript. إعداد100%/actual size مطلوب، مع إلغاء رؤوس المتصفح وهوامشه الإضافية. لا ادعاء اختبار جهاز فعلي أو silent printing أو ZPL؛ اختيار الأجهزة مؤجل حسب المستخدم.

## الاختبار والمصادر
اختبارات PostgreSQL للصلاحيات والشركة وسحب الدور والتباس SKU/باركود وعدم أثر على الرصيد، وحدود العدد والقالب. Chromium للمعاينة وprint media والصفحات والهاتف، وفك صورة الرمز بقارئ مستقل zxing-cpp3.1.1 في مجموعة browser الاختبارية فقط. لا استبدال بفك ناتج من المولد نفسه أو تجاهل الاختبار عند غياب القارئ. نتائج التنفيذ في TEST_LOG.

المراجع الأولية: [python-barcode على PyPI](https://pypi.org/project/python-barcode/0.16.1/)، [Code128](https://python-barcode.readthedocs.io/en/stable/supported-formats.html)، [خيارات SVGWriter](https://python-barcode.readthedocs.io/en/stable/writers.html)، [قارئ zxing-cpp](https://pypi.org/project/zxing-cpp/3.1.1/). قرارات المقاسات والتفويض وحد النسخ للمشروع؛ لا يستنتج منها توافق أجهزة أو GS1.
