# نطاق التحقق R05

- واجهة RTL عربية: إدارة الأعضاء والفروع والمستودعات والأدوار الثابتة والتدقيق والملكية، حالات فارغة وأخطاء ونجاح وبحث وتقسيم صفحات.
- التفويض في الخدمات لكل POST، منع تعديل بريد المالك من مسؤول أقل صلاحية، ومعرفات شركة أخرى مرفوضة، ومنع تفعيل دعوة دون قبول.
- SMTP قابل للإعداد دون أسرار في Git؛ سجل انتظار محلي للشركة لا يحفظ bearer token، عامل منفصل محدود المحاولات والمهلة وإلغاء الروابط المستبدلة.
- متصفح Chromium: دخول وCSRF حقيقيان، HTMX يحتفظ بسياق الصفحة، قبول دعوة، حساب محدود، عرض 390/768/1440، dialog بلوحة المفاتيح والتخطي، ونموذج مع أخطاء دون JavaScript.
- فحص الصور الصناعية لسطح المكتب والهاتف يدويًا، وتصحيح تمدد RTL الناتج عن موضع النصوص المخصصة لقارئ الشاشة.
- إعادة اختبارات الأساس وR04 والسياسة والترحيلات والمنح وفحوص الخطة والحصر. الأدلة النهائية في TEST_LOG وSTATUS؛ القائمة وحدها ليست نتيجة نجاح.

التالي R06 للعملاء والفحوص والوصفات بتاريخ محفوظ وصلاحيات الفروع. لم تبدأ وحدات البيع أو المخزون أو المال أو الربط الخارجي في R05.
